# 포즈 참조 삽화 제작

장면에 맞는 웹 포즈를 찾아 실제 참조파일로 생성·편집까지 수행한다. 함께 설치한 `direct-illustration-poses`의 검색기·검증 태그 인덱스를 재사용한다. 별도 검색 코드나 이미지 목록을 복제하지 않는다. `<검색스킬>`은 현재 SKILL.md의 부모 디렉터리와 같은 사용자 스킬 루트에 있는 direct-illustration-poses 디렉터리다. 임의의 PC 경로를 가정하지 않는다. 의존 스킬이 없으면 같은 저장소의 두 스킬을 함께 설치해야 함을 알린다.

## 참조 찾기

1. 장면의 행동·감정·소품·인원·시점을 정리한다. 입력 이미지는 실제로 열어 자세 예시인지, 외형 기준인지, 편집 대상인지 구분한다. 가려진 손발·인물 기준 좌우는 추정 확정하지 않는다.
2. `direct-illustration-poses` 지침으로 모호한 표현을 자세 특징으로 바꾸고 웹 후보를 검색한다. `python "<검색스킬>/scripts/gallery.py" search "<장면>" --limit 5` 또는 관찰한 특징 JSON의 `--features`를 사용한다. 전체 인덱스는 모델 문맥에 읽지 않는다.
3. 선택 후보의 미리보기와 개별 원본을 실제로 연다. 태그에 관찰 이력이 있어도 이번에 받은 원본의 손·관절·접촉·인원·시점을 확인한다. `missing` 조건을 만족했다고 보고하지 않는다. 후보가 충분히 적합하면 선택을 사용자에게 떠넘기지 않고 진행하되 실제 차이는 짧게 설명한다.

## 파일 준비와 생성

캐릭터/편집 대상 파일은 얼굴·외형·의상·장비·재질을, 포즈 PNG는 자세·구도만 담당한다. 실제 입력 파일을 모두 열고 작품의 좌우·장비 위치를 유지한다. 요청 없는 반전을 하지 않는다. 일반 인물을 새로 그리는 요청에는 캐릭터 기준 이미지를 필수로 요구하지 않는다.

`python "<검색스킬>/scripts/gallery.py" prepare --pose-file "<pose.png>" --pose-id <웹ID> --scene "<장면>" --character "<캐릭터.png>" --constraints "<보존 조건>" --out "<새 작업폴더>"`

캐릭터 파일이 있을 때만 `--character`를 추가한다. prepare는 프롬프트·실제 파일 복사본·manifest·생성 도구 인수를 준비하며 직접 생성하지 않는다. 캐릭터 미제공 상태는 특정 외형 유지의 미확정 표시이며 일반 인물 생성 요청 전체를 막지 않는다.

사용 가능한 `imagegen` 스킬을 읽고 기본 내장 이미지 생성 도구를 호출한다. 준비한 prompt와 **실제로 확인한 포즈 PNG 및 캐릭터/편집 대상 파일**을 도구의 참조 입력으로 전달한다. URL·ID·자세 설명만 전달한 것을 포즈 이미지 참조라고 부르지 않는다. 생성 요청이 이미 있으면 다시 허락을 묻지 않는다. “참조 준비까지만”이면 도구를 호출하지 않는다. CLI/API 유료 경로로 임의 전환하지 않는다.

출력 이미지를 실제로 확인해 자세·접지·손·소품 접촉·인원·좌우와 외형 보존을 점검한다. 요청된 결과를 보여주고 사용한 포즈 출처와 남은 차이를 짧게 알린다. 생성 도구가 없으면 실제 참조파일과 프롬프트를 반환한다.

## 출처 실패

검색 스킬의 출처 안내를 적용한다. 해당 사이트 자료를 사용할 수 없으면 용도를 허용하는 다른 웹 자료를 찾는다. 대안 이미지를 실제로 확인하고 `--pose-source external --source-url <페이지> --rights-note "<확인한 범위>"`로 출처를 기록한다. 적합한 포즈 이미지가 없으면 일반 자세 설명과 실제 편집 대상 파일로 진행하되 포즈 이미지가 없음을 명시한다. 이미지의 정확한 일치가 필수라면 그 한계를 알린다. 출처 조건을 숨겨 도구 판단을 속이지 않는다. 도구가 거절하면 실제 사유를 알리고 허용되는 수정으로 대응한다.
