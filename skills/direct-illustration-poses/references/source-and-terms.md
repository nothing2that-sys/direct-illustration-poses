# 출처와 이용 범위

출처: [AI Pose Gallery / POSE-DB-01](https://ai-pose-gallery.pages.dev/), 제작자 [ギア](https://x.com/giaaibusi).

2026-10-30 확인한 사이트 안내의 요지이며, 사용 시 사이트의 최신 안내를 다시 확인한다.

- 작품 제작의 상업적 이용·편집·참고 이용은 허용한다고 안내한다.
- 생성 참조로 한 장씩 사용할 수 있다.
- 이미지 데이터 자체는 원본·가공본 모두 재배포·전재·재판매할 수 없다.
- 도구를 통한 자동 취득을 포함한 이미지 일괄 다운로드와 이미지 배포·미러링을 금지한다.
- 얼굴 없는 마네킹 선화이며, 얼굴·의상·배경은 별도 참조나 프롬프트로 보완한다.
- 크레딧은 선택 사항이며 자료는 무보증이라고 안내한다.
- 사이트는 실존 인물·미성년자를 나타내는 용도 및 공서양속에 반하는 용도에 사용하지 말라고 안내한다.

이 저장소의 MIT 라이선스는 직접 작성한 코드·스킬 문서에만 적용된다. 외부 사이트 이미지나 목록에 대한 새로운 권리를 부여하지 않는다. 사이트 이미지·썸네일·목록 덤프를 저장소에 포함하지 않는다. 실시간 검색을 위해 HTML에 포함된 텍스트 메타데이터만 로컬에서 읽으며 검색 자체는 이미지를 요청하지 않는다. 선택한 후보의 preview 또는 original을 한 번에 한 파일만 가져오는 명령을 제공한다. 호출을 반복해 전체 라이브러리를 수집하지 않는다.

사이트 이용 안내가 바뀌거나 다운로드가 제한되면 그 안내를 우선하고, 추측한 URL·우회 경로·개인 Drive 복사본을 대체 공급원으로 사용하지 않는다.
